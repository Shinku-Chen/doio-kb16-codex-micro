# v0.6.0-qmk · Codex L0 / VIA 自定义切层

## 中文

仅适用 **DOIO KB16-01 Rev2 / APM32F103CBT6 / 128 KB Flash / Maple Bootloader**。

- **第一页 L0 是 Codex，L1–L3 是普通 VIA 层**。OLED 的 1/2/3 分别对应 L1/L2/L3，即 VIA 第 2/3/4 页；Codex 显示 Logo/任务页。
- Codex 层五处直接执行 VIA 第一页：左上、右上、左下方键，以及 A/B 旋钮按下。六个 AG、七个 ACT、三个旋转轴和 C 按下保持原生映射。实际普通 HID 输出会临时显示在屏幕上。
- **完全取消固定长按退出、延迟短按重放和专用退出白光**。自己在五处设置 MO/TO 等层动作；推荐左下 `MO(1)`，按住临时使用普通 L1，松开回 Codex；普通层配 `TO(0)` 返回。
- 保留标准 QMK 高层优先语义。普通透明键继承普通基底 L1，不漏出 Codex 的 AG/ACT；使用源层缓存配对跨层松开，不实现强制低层覆盖。
- 真正断电启动保留十秒 `VIA WAITTING`；有效 VIA 命令锁定身份至断电，否则复位进入 Codex 身份、默认 L0。切层不改变 USB 身份，Codex 下可执行已保存的普通 VIA 配置，但不能同时在线改键。
- 一次迁移旧 L3→新 L0、旧 L0/L1/L2→新 L1/L2/L3，包括键位、encoder map 和层动作目标。已有 0.5.0 五处自定义不再次清空，宏内容、EEPROM 起址/容量不变。原 Codex `MO(0)` 会变为 `MO(1)`。
- 其他原生控制、宿主颜色/亮度/灯效微调、第四排环境灯、OLED 留边与一小时空闲策略不变。无 Input 改键、Mapper 或额外常驻程序。

**升级前先导出 VIA 配置并保留官方回退镜像**。迁移期间保持供电；不要直接导入未转换页序的旧备份。五处全新默认无动作，没有固定长按保底，请自行保留切层入口。

73 组固件检查（ASan/UBSan）、13 项打包测试及 QMK 编译通过。此前同源 main 流水线产物已刷入，设备版本与状态确认 `0.6.0-qmk` / Codex L0，用户反馈“正常的”。本次发布准备只改文档，固件源码与该已测版本一致；总体反馈不等于一小时休眠、光度/频率/时长精测或 Flash 读回。发布流程本身不再次刷机。

附件全部由 GitHub Actions 从本标签源码生成：BIN、HEX、VIA 定义、BUILD-INFO.json、SHA256SUMS。新产物的提交、运行、体积与摘要见自动生成资产表和 BUILD-INFO.json；使用 SHA256SUMS 校验，不能用本地镜像替代。

刷写：断开 USB 后拆机，露出内部 RESET；接回 USB、先启动等待，再短按内部 RESET，捕获 `1EAF:0003`，仅写 Maple alt 2 应用区 `0x08002000`。不改 Bootloader/读保护，不把 HEX 当原始 BIN，写入完成后不因仍在 DFU 或复位返回 74 就盲目重刷。关闭 VIA，断电五秒正常重插，十秒后进入 Codex。详见 [使用与刷写](https://github.com/Shinku-Chen/doio-kb16-codex-micro/blob/v0.6.0-qmk/docs/usage.md)。

## English

For **DOIO KB16-01 Rev2 / APM32F103CBT6 / 128 KB Flash / Maple Bootloader only**.

- **Codex is L0, the first VIA page; L1–L3 are ordinary layers.** OLED numbers 1/2/3 represent L1/L2/L3, editor pages 2/3/4. Codex retains logo/tasks and temporary actual-output labels.
- Five positions execute first-page VIA directly: both top corner keys, bottom-left, and A/B clicks. Native AG/ACT, knob rotations and C click stay fixed.
- **No fixed exit hold, delayed tap replay or dedicated exit-white feedback.** Configure switching yourself: `MO(1)` holds ordinary L1 and returns on release; `TO(0)` returns from an ordinary layer.
- Standard QMK highest-layer priority remains. Ordinary transparent keys inherit L1, not native Codex controls; source-layer caching pairs releases across switches.
- Keeps the ten-second `VIA WAITTING` startup window. Valid VIA traffic locks VIA identity until power-off; otherwise the board resets into Codex identity on L0. Switching layers does not switch USB identity.
- Rotates old L3→new L0 and old L0/L1/L2→new L1/L2/L3, including encoder maps and layer-action targets. Existing 0.5.0 custom keys and macros are retained, with unchanged EEPROM addresses/capacity. Export first; convert old-order backups before importing. Fresh custom positions are unassigned, so reserve switching keys yourself.
- Host light colors/effects/brightness adjustments, fourth-row ambient, OLED margins, sleep policy and native controls are unchanged. No Input remapping, Mapper or additional daemon.

73 firmware groups, 13 bundle tests and compilation passed. An earlier main build with the same firmware source was flashed and answered `0.6.0-qmk` / Codex L0; the user reported normal operation. Release preparation changes documentation only. This is overall acceptance, not a new one-hour idle test, optical/timing measurement or flash readback; the release workflow does not flash hardware.

All five assets are built by GitHub Actions from this tag, not uploaded from a local build. Verify BUILD-INFO.json, SHA256SUMS and the workflow provenance. Unplug before opening the case; reconnect/start DFU waiting, then press internal RESET. Write only Maple alt 2 at `0x08002000`, never the bootloader or read protection. Do not flash HEX as raw BIN or blindly reflash after a completed download. See [flashing instructions](https://github.com/Shinku-Chen/doio-kb16-codex-micro/blob/v0.6.0-qmk/docs/usage.md).
