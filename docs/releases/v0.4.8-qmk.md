# v0.4.8-qmk · 10 秒启动 / 1 秒切层

## 中文

仅适用 **DOIO KB16-01 Rev2 / APM32F103CBT6 / 128 KB Flash / Maple Bootloader**，不要刷 Rev1、无线版或其他硬件。

### 本版变化

- 通电后的 VIA 命令窗口从 **30 秒改为 10 秒**；期间 OLED 显示 `VIA WAITTING`，不显示 DOIO 页。
- Codex 第四层（QMK **L3**）左下角长按从 **5 秒改为 1 秒**，进入普通 L0；普通层设置 `TO(3)`（Any：`0x5203`）返回 Codex。
- 完整中文 README + 英文 README，加入七张由真实固件测试帧生成的 OLED 合成预览、键位/旋钮/LED 对照、灯效颜色/亮度/样式、休眠和原厂差异。
- 保留宿主 RGB 与既定 AG/环境微调、心跳/重复报文续时、一小时 RGB/OLED 联动休眠和现有键位存储语义；不增加 Input/Mapper 或电脑端常驻程序。

### 使用要点

提前打开 VIA 并在 Design 加载附件 `kb16_codex_via.json`；键盘断电重插后 **10 秒内授权并成功读键位**，随后可一直改键到断电，不必十秒内完成全部编辑。VIA L0–L2 执行改键；第四页 L3 虽可编辑保存，实际始终是固定 Codex 布局。

没有 VIA 命令时，10 秒后自动复位为 Codex 身份并默认 L3。**切层不切 USB 身份**；若锁定过 VIA，改完需断电重插、关闭 VIA 并等待窗口超时，Codex App 才能连接专用接口。

### 资产与校验

- `doio_kb16_rev2_codex_micro_v0.4.8-qmk.bin`：Maple alt 2 应用镜像，含 DFU suffix，**50,848 字节**。
- `doio_kb16_rev2_codex_micro_v0.4.8-qmk.hex`：带应用区地址的 Intel HEX。
- `kb16_codex_via.json`：VIA 定义，4×5 矩阵、三旋钮、四层。
- `SHA256SUMS`：以上三份附件的 SHA-256。

BIN SHA-256：

```text
8deaf0da59ca51b900276e1b3225496559035ce364c5a39e2554ed7efaf7e988
```

### 验证与安全边界

**60 项离线检查和 QMK 编译通过**，覆盖 9,999/10,000 ms 窗口、999/1,000 ms 长按、VIA 锁定、四层/EEPROM、双 HID、灯光、OLED 和共享休眠；C 测试启用 ASan/UBSan。固定 QMK 基线 `f5db962110615fd263c3ebf9f0402e7c2b08fbe4`，Arm GNU Toolchain 15.3.Rel2。

上一版 `0.4.7-qmk` 已刷入、核验版本且用户反馈正常；**本版未刷入实机**，不将旧版验收等同于新版时长实测。固件支持 13 个灯槽，但已检查的 Cindy 仍只下发 6 路；OLED 仍为六格色类估计，不是可靠的业务状态或额度数据。

刷前导出 VIA 配置、保留官方回退镜像并核对校验和。仅写应用区 `0x08002000`，不擦写 Bootloader 或修改读保护。BIN 与 HEX 是两种格式，选择匹配工具的一种，不要将 HEX 当作原始 BIN 传给 dfu-util。完整步骤见仓库 `docs/usage.md`。

## English

For **DOIO KB16-01 Rev2 / APM32F103CBT6 / 128 KB Flash / Maple Bootloader only**.

- Startup VIA handshake window: **10 seconds** instead of 30.
- Fixed Codex fourth layer **L3**: hold the bottom-left key for **1 second** to exit to L0. Configure `TO(3)` (`0x5203`) in ordinary layers to return.
- Expanded Chinese and English READMEs with framebuffer-derived OLED previews, mappings, light/color/brightness tables, sleep rules and differences from original hardware.
- Host RGB, existing light adjustments, EEPROM mapping and one-hour RGB/OLED policy remain unchanged. No Input remapping, Mapper or extra daemon.

Load the included VIA JSON before power-cycling, then authorize/read the keyboard within 10 seconds. Successful VIA communication locks VIA identity until power-off; editing can continue beyond the window. L0–L2 execute VIA mappings; page 3 is editable storage but always runs the fixed Codex layout. Layer changes do not change USB identity: power-cycle without VIA traffic to obtain the Codex interface.

Assets: BIN (50,848 bytes, Maple application at `0x08002000`), addressed Intel HEX, VIA JSON and SHA256SUMS. The BIN hash appears above. Choose the format appropriate to your flashing tool. Do not flash HEX as raw binary, overwrite the bootloader or change read protection; export your layout and retain an official recovery image first.

**QMK build and 60 offline checks passed. This version has not been flashed during this release.** The preceding `0.4.7-qmk` was hardware-verified and reported working. Thirteen firmware light slots still require host support beyond the six slots in the inspected Cindy build. See `README.en.md` and `docs/development.md` for details and validation limits.
