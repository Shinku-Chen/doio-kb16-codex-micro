# v0.4.9-qmk · OLED 独立息屏 / Codex Logo

## 中文

仅适用 **DOIO KB16-01 Rev2 / APM32F103CBT6 / 128 KB Flash / Maple Bootloader**。

- 修复任务灯全部关闭后 OLED 熄灭、进入 Codex 也看不到 Logo：屏幕不再沿用 RGB 的聚合关灯条件。
- 进入第四层 Codex（QMK L3）从首个可显示帧起展示完整约 1 秒 Logo+CODEX；无任务灯分配时持续显示 Logo，全部任务明确 off 后回到 Logo。有任务时仍显示原六格状态估计，不增加扩展槽分页。
- OLED 仅因 USB 挂起或一小时无输入且无有效宿主通信而关闭；心跳和重复有效报文继续续时。B=0、黑色或动画暂停不等于释放任务；环境灯不算任务。
- **RGB 的关灯逻辑、宿主原色与既定灯效/亮度微调不变**。保留 10 秒 `VIA WAITTING`、L3 左下角长按 1 秒回 L0、普通层 `TO(3)` 返回、四层及 EEPROM 配置。不增加 Input/Mapper/额外常驻程序。

63 项固件离线检查（C 启用 ASan/UBSan）、13 项打包检查及 QMK 编译通过。正式资产由 GitHub Actions 从标签源码测试、编译并发布，实际来源/体积/哈希见本页自动生成的资产表、`BUILD-INFO.json` 与 `SHA256SUMS`。**本版尚未刷入实机**；0.4.8 的启动/切层验收不代表新版 OLED 行为已实测。

下载 BIN、HEX、VIA 定义及校验元数据；先导出 VIA 配置、保留官方回退镜像并校验。刷机需要断 USB 拆机，再接 USB 启动等待，短按 PCB 内部 RESET 捕获 `1EAF:0003`，仅写 Maple alt 2 应用区 `0x08002000`。不要把 HEX 当原始 BIN，不擦写 Bootloader 或改读保护，复位返回 74 时先核验枚举/版本，不自动重刷。完整步骤见 `docs/usage.md`。

## English

For **DOIO KB16-01 Rev2 / APM32F103CBT6 / 128 KB Flash / Maple Bootloader only**.

- Fixes OLED blackout after all task lights are cleared, which also hid the Codex entry logo. Host RGB all-off no longer powers down OLED.
- Shows Logo+CODEX for a full second from the first visible Codex-layer frame. With no assigned task lights, the logo stays or returns; assigned tasks retain the existing six-cell page. Zero brightness, black or frozen animation does not release a task, and ambient is not a task.
- OLED sleeps only on USB suspend or one hour without input and valid host traffic. Valid heartbeats and repeated packets renew the timer. **RGB policy, host colors, brightness/effect adjustments and local feedback remain unchanged.**
- Keeps the 10-second VIA window, one-second bottom-left exit from L3, `TO(3)` return, four layers and EEPROM data. No Input remapping, Mapper or extra daemon.

63 firmware regression groups, 13 bundle checks and QMK compilation passed. Official assets are built and published by GitHub Actions from the tag; verify BUILD-INFO.json and SHA256SUMS. **Not flashed yet**; previous 0.4.8 hardware acceptance does not validate this OLED update.

Back up VIA and retain an official recovery image. Unplug before opening the case, reconnect/start DFU waiting, then press the PCB's internal RESET. Write only Maple alt 2 at `0x08002000`, never the bootloader or read protection. Do not flash HEX as raw BIN or automatically reflash after reset code 74. See `README.en.md` and `docs/usage.md`.
