# v0.7.0-qmk · Codex 层 VIA 优先 / 空键回退

## 中文

仅适用 **DOIO KB16-01 Rev2 / APM32F103CBT6 / 128 KB Flash / Maple Bootloader**。

- **L0 全部 16 个方键、三个旋钮按下及六个旋转方向均可由 VIA 第一页覆盖**。普通键、修饰组合、宏、媒体、鼠标及 MO/TO 等层动作优先执行，不再同时发送该位置原生 Codex 动作。
- **`KC_NO` / `KC_TRNS` 恢复对应位置的原生 AG/ACT/JOY/ENC 功能**；五个原无功能位置清空后仍无动作。仅 L0 使用此规则，普通 L1–L3 的禁用和透明继承语义不变。
- 原有 AG/ACT/JOY/ENC/历史切层内部码作为默认占位，恢复本位置原生功能，不用来搬移或注入原生事件。L0 的空键不能用于禁用原生功能。
- 保留四层顺序：L0 Codex，L1–L3 普通 VIA。推荐 `MO(1)` 按住普通 L1，松开回 Codex；普通层用 `TO(0)` 返回。无固定长按退出，沿用 QMK 高层优先及跨层松开缓存。
- 保留十秒 `VIA WAITTING` 和双 USB 身份；VIA 在窗口内收到有效命令后锁定身份至断电，切层不改变 USB 身份。Codex 下执行已保存的 VIA 配置，但不能同时在线改键。
- 普通 HID 输出继续临时显示真实键名，松开约 900 ms 恢复 Logo/任务页。宿主任务灯仍按原物理灯位显示，不随按键覆盖重新映射；原色/亮度/效果微调、第四排环境及一小时休眠不变。

### 升级提醒

**先导出 VIA 配置，检查 L0 所有按键及三个旋钮，并保留官方回退镜像。** 从 0.6.0 升级不增加迁移、清空或改变 EEPROM 地址；从前保存但未执行的 L0 编辑现在也会生效。不想覆盖原生功能的位置清空为 KC_NO/KC_TRNS。更早版本仍执行已有页序/层动作迁移，不要直接导入未转换的旧页序备份。

正式附件由本标签的 GitHub Actions 从源码测试、编译并校验后发布：BIN、HEX、VIA 定义、BUILD-INFO.json、SHA256SUMS。来源及最终摘要以下方自动生成资产表与 BUILD-INFO.json 为准；不使用本地上传镜像。刷机先断开 USB 拆外壳，再使用 PCB 内部 RESET，仅写 Maple alt 2 应用区，不改 Bootloader 或读保护；完整步骤见 README / docs/usage.md。

### 验证边界

75 组固件检查（C 使用 ASan/UBSan）、13 项打包测试及本地 ARM 编译通过，覆盖所有位置回退、VIA 覆盖、原生 AG/ACT/C 按压上的 MO、跨层松开及无重复事件；正式流水线再次执行回归和镜像/来源校验。**本版未刷机、未做实机或光度验收**，实机基线仍为已获整体使用确认的 0.6.0；流水线不操作硬件。

## English

Only for **DOIO KB16-01 Rev2 / APM32F103CBT6 / 128 KB Flash / Maple Bootloader**.

- VIA page 1 overrides all 16 L0 keys, three encoder clicks and six rotation directions. Ordinary keys, modifiers, macros, media, mouse and layer actions execute without duplicate native Codex events.
- `KC_NO` / `KC_TRNS` restores the native AG/ACT/JOY/ENC function at that position, or no action at the five spare positions. This applies only to L0; ordinary L1–L3 keep standard disabled/transparent behavior. Internal native codes remain placeholders, not a way to relocate native events.
- L0 remains Codex; L1–L3 remain ordinary VIA. Configure `MO(1)` for momentary L1 and `TO(0)` to return. No fixed exit hold; standard QMK layer priority and cached releases remain unchanged.
- Keep the ten-second VIA window and separate USB identities. Saved VIA mappings work under the Codex identity; live VIA remapping still requires the startup handshake.
- Actual ordinary HID output still appears temporarily on OLED. Host task lighting stays at its original physical slots; colors, brightness/effect adjustments, fourth-row ambient and one-hour sleep policy do not change.

**Export and inspect every L0 key/click/rotation before upgrading.** Existing mappings, macros and EEPROM addresses are retained without a new 0.6→0.7 migration. Previously saved but ignored L0 mappings now become active; clear them to KC_NO/KC_TRNS to restore native defaults. Older releases retain their existing migration path.

Assets are built and published only by this tag's GitHub Actions, with BUILD-INFO.json and SHA256SUMS provenance. Use the PCB's internal RESET after safely opening the case; write only the Maple alt 2 application area. Never modify the bootloader or read protection.

75 firmware groups, 13 packaging tests and local ARM compilation passed; CI repeats tests and artifact validation. **Not flashed or hardware-accepted in this release**; hardware still runs the accepted 0.6.0 baseline. CI never flashes hardware.
