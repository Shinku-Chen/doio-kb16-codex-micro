# Codex Micro ↔ KB16 位置对应图

> 按 4×4 物理位置对应。Codex Micro 的左上角是编码器、右上角是摇杆，不是按键；KB16 对应位置的两个键空出，编码器/摇杆功能交给 3 个旋钮。

## Codex Micro 4×4

```text
┌────────┬────────┬────────┬────────┐
│ ENC    │ AG00   │ AG01   │ JOY    │
├────────┼────────┼────────┼────────┤
│ AG02   │ AG03   │ AG04   │ AG05   │
├────────┼────────┼────────┼────────┤
│ ACT06  │ ACT07  │ ACT08  │ ACT09  │
├────────┼────────┼────────┼────────┤
│ Mic    │ ACT11  │ ACT12  │ empty  │
└────────┴────────┴────────┴────────┘
```

- `ENC`：左上编码器（CC / CW / Press）
- `JOY`：右上平面摇杆（↑ → ← ↓）
- `ACT11`：官方双宽 Mic 的第二个位置（ACT10_ACT11）；当前 KB16 固件不发 ACT11
- `empty`：官方 13 键布局里的空位
- 触摸传感器在**左下角**（4×4 键区外），用于切层；它不是 Mic 键

> 官方底排的 Mic 是双宽键帽，覆盖 ACT10 + ACT11 两个开关位置；上图拆成 `Mic | ACT11` 是为了和 KB16 的 1u 键位对应。  
> 左下角还有一个独立的触摸传感器（切层），它不在 4×4 键位里，也不是 Mic。

## KB16 位置对应

```text
┌────────┬────────┬────────┬────────┐
│ UNUSED │ AG00   │ AG01   │ UNUSED │
│ (=ENC) │        │        │ (=JOY) │
├────────┼────────┼────────┼────────┤
│ AG02   │ AG03   │ AG04   │ AG05   │
├────────┼────────┼────────┼────────┤
│ ACT06  │ ACT07  │ ACT08  │ ACT09  │
├────────┼────────┼────────┼────────┤
│ ACT10  │ ACT11  │ ACT12  │ UNUSED │
│ (Mic)  │ (split)│        │ (empty)│
└────────┴────────┴────────┴────────┘
```

- 左上键：对应 Codex 的编码器位置，**不用**；编码器功能交给旋钮 A。
- 右上键：对应 Codex 的摇杆位置，**不用**；摇杆功能交给旋钮 B/C。
- 右下键：对应 Codex 的空位，**不用**。
- 下排中间：对应官方双宽 Mic 的 ACT11 位置；拆分模式可启用为独立 ACT11，当前上游固件还不发送。
- 左下角触摸传感器：KB16 没有；切层用旋钮按下/System 层，不占用 R4C1 的 Mic 键。
- 实际参与 Codex 的键：AG00-AG05、ACT06-ACT09、ACT10、ACT11、ACT12，共 13 个（拆分模式）。

## 3 个旋钮

| 旋钮 | 对应 Codex 控制 | 动作 |
|---|---|---|
| 旋钮 A | 左上编码器 | CC / CW / Press → `ENC_CC` / `ENC_CW` / `ENC_SW` |
| 旋钮 B | 右上摇杆 X | 顺时针 = 右，逆时针 = 左 |
| 旋钮 C | 右上摇杆 Y | 顺时针 = 上，逆时针 = 下 |

旋钮 A/B/C 对应 KB16 的哪三个实体旋钮，可以按手感分配；建议把最大的旋钮留给编码器，两个小旋钮做 X/Y。

## 关于 Mic

Mic 不是独立硬件，官方是双宽键 `ACT10 + ACT11`，可以合并，也可以拆分：

- **合并模式**：`ACT10_ACT11` 作为一个 Mic；KB16 可用一个键发 `ACT10`，另一个键空着或放别的功能。
- **拆分模式**：ChatGPT 的 `separateMicrophoneKeys` 打开；`ACT10`、`ACT11` 是两个独立槽，KB16 的 R4C1/R4C2 分别发 `ACT10`/`ACT11`，每个都可以绑不同功能。
- 当前上游固件只发 `ACT10`，不发 `ACT11`；拆分模式需要新增 `ACT11` action 和配置。
- Mic 可以与其他 ACT 互换；拆分后 `ACT10`/`ACT11` 也可以各自换位置。
- 官方宽键没有 KB16 双宽键帽，但两个 1u 键可以模拟它的两个半键。

## 关键差异

- **左上/右上**：官方是编码器/摇杆，不是按键；KB16 对应键空出，功能移到 3 个旋钮。
- **AG 灯**：6 个 AG 键在 R1C2、R1C3、R2C1-R2C4，任务灯跟着这 6 个位置。
- **ACT11**：官方是双宽 Mic 的第二个半键；KB16 R4C2 可在拆分模式启用 ACT11，当前上游还不发送。
- **触摸传感器**：官方在机身边缘；KB16 没有，用旋钮按下/System 层切层替代。
- **旋钮数量**：官方 1 个；KB16 3 个，建议 1 个编码器 + 2 个摇杆轴。
- **当前固件状态**：现有默认 `native_keys` 还是旧的 16 键布局（右上 2×2 当摇杆）；这份位置映射是目标方案，落地时需要改 `native_keys`、旋钮动作和校验。
