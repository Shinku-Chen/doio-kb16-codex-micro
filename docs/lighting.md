# 宿主灯光映射：颜色、亮度和样式

本规则对应 `firmware/keymaps/codex_micro_via_v1/`。2026-10-30 已完成源码修改、回归测试和 QMK 编译；先刷 `15472a93…` 灯光版，后刷 `78a520ff…` 修复版，并由实机返回 `0.2.0-qmk` 确认新版运行。本轮八组灯光项目均已由用户目视确认，不等于每个实体输入、VIA/OLED 功能或光度/闪烁频率精确测量均已验收。

随后用户要求录音海绿从快闪改为常亮，已并入当前 `0.3.0-qmk`（四层：L0–L2 普通 VIA，L3 固定 Codex；OLED 只显示 0–3 层号），22 项离线检查和编译通过，已刷入并核验新版本及切层状态；本轮尚未重测录音灯光。灯光仅在 L3 使用 Codex 渲染；下方 `0.2.0-qmk` 的五层和海绿快闪记录仅为历史验收，不是新常亮规则的实机结果。

当前源码 `0.4.8-qmk` 仅缩短启动窗口为 10 秒、Codex 退出长按为 1 秒；60 项离线检查及编译通过，本版流水线固件已刷入并通过版本核验，10 秒启动与约一秒退出/返回获用户实机确认；不代表其他项目已重测。上一版 `0.4.7-qmk` 已刷并获用户正常反馈。原色、微调及一小时兜底/心跳重复报文续时均不变；当前 Cindy 仍只下发六路，扩展映射见 [兼容性评估](lighting-compatibility.md)。

用户对 `0.4.1-qmk` 的实机反馈：第四排确实呼吸，但感觉不是低亮度；AG 和 OLED 基本显示正常，状态一直显示 OTHER。核对本机 Cindy 已安装构建（sourceCommit `b3dd8436228135aa8be9827d204e4e5eaf9316b4`）的灯光帧逻辑发现，它使用另一套 RGB。旧代码仅精确匹配 GPT 色，因此 Cindy 的运行蓝漏过降亮，任务状态也落入 OTHER。此处依据已安装宿主代码及离线报文回放，不声称已经抓取 USB 实时输出或完成修复版目视验收。

## 已确定的规则

- 保留任意宿主下发的原始 RGB、亮度、效果和速度，不按 App 名称/精确 RGB 选择预设颜色，不把白色替换成偏紫白。
- AG 的 `snake` 不限定任务状态，任意颜色均转为原色 `0–100% × B` 呼吸，不叠加 Idle 的 5%；第四排环境 `snake` 映射同步呼吸，只有当前任务运行的蓝色提示降为 `0–10% × B`，白色处理和其他颜色仍为 `0–100% × B`，均跟随宿主速度，0 暂停当前相位。录音海绿环境提示继续例外常亮，颜色和宿主亮度不变；其他灯效类型不改。
- Idle 常亮保留白色色相，亮度乘以 5%；首刷 10% 经用户反馈仍偏亮，最终改为 5%。用户随后明确普通常亮为 100%、呼吸为 0–100%，因此呼吸不再叠加 Idle 的降亮系数。
- 六个 AG 继续独立显示宿主灯态；OLED 状态是按灯色推断，不能保证任意主题颜色对应的业务语义。
- GPT 的 ambient 环境灯映射第四排全部 LED 12–15（切层键、ACT10/ACT11/ACT12），四颗呼吸同步，不覆盖 AG。也接收 `lights.preview.underglow`。
- 普通 ACT 无环境提示时保留按住白光；第四排 ACT 的环境提示优先于按压白光，切层键按住时仍优先白光反馈，1 秒退出不变。录音海绿保持常亮，白色处理/蓝色运行提示改为同步呼吸。
- 不把 GPT 的 keys 区域铺成整盘背景色，保留普通 ACT 默认灭灯的既定规则。空位保持熄灭。

表中 `B` 表示对应宿主报文里的亮度 `b`，0–100%。普通常亮为 `100% × B`，普通呼吸为 `0–100% × B`；Idle 常亮例外为 `0.05 × B`，运行蓝色环境 snake 的呼吸例外为 `0–10% × B`。所以全局亮度 50% 时普通常亮 50%、普通呼吸 0–50%、Idle 常亮 2.5%、运行环境呼吸 0–5%。`B=0` 时宿主控制的灯为 0，本地按压白光不受 B 控制。

## AG 任务灯完整对照

颜色是宿主基色，不是降亮后的 PWM 数值。下表描述常见颜色约定及保留的本地调整，不定义固定输出 RGB。任务含义以宿主为准；固件只观察灯光参数。彩虹/渐变按对应动画生成变化色，不使用业务状态预设色。

| 按色类推断的状态 | 基色 | 亮度 | 样式 |
|---|---|---|---|
| Idle / 空闲，未选中 | 宿主白/灰系，保留冷暖色调 | `5% × B` | 常亮 |
| Idle / 空闲，选中或宿主指定脉冲 | 宿主白/灰系 | `0–100% × B` | 呼吸，不叠加 Idle 常亮的 5% 系数 |
| 正在运行，未指定呼吸 | 宿主蓝色系 | `B` | 常亮 |
| 完成且未读，未指定呼吸 | 宿主绿色/海绿色系 | `B` | 常亮 |
| 等待审批，未指定呼吸 | 宿主橙/黄色系 | `B` | 常亮 |
| 等待回复，未指定呼吸 | 宿主橙/黄色系 | `B` | 常亮 |
| 错误，未指定呼吸 | 宿主红色系 | `B` | 常亮 |
| 上述非 Idle 状态，选中或宿主指定脉冲 | 保持该状态原色 | `0–100% × B` | 呼吸，跟随报文速度 |
| 任意任务状态，宿主指定 snake（兼容规则，不代表常规任务一定下发） | 保持宿主原色 | `0–100% × B` | 转为呼吸，跟随报文速度，0 暂停当前相位 |
| 未分配任务 / `off` | 无光 | 0 | 熄灭 |

协议没有独立 Idle 字段，固件把白/灰系作为 Idle 外观约定。5% 降亮仅作用于这类 AG 常亮，不作用于呼吸、其他动画、环境白色或本地按住反馈。暖白、冷白仍按原通道比例缩放，不能改成统一纯白。

AG00–AG05 的物理位置依次是 R1C2、R1C3、R2C1、R2C2、R2C3、R2C4，LED 编号为 1、2、4、5、6、7。

### 通用颜色分类与推断边界

分类只返回色类，不返回替代 RGB。先识别全黑，再按相对饱和度识别白/灰，其余按整数近似色相 H（0–359°）划分，不区分 App 来源：

| 色类 | 条件 | OLED 推断 | 环境 snake 调整 |
|---|---|---|---|
| 黑 | RGB 全 0 | OTHER，无业务基色信息 | 按效果渲染；彩虹/渐变仍可有光 |
| 白/灰 | 饱和度不超过 12% | IDLE | 0–100%×B 呼吸 |
| 红 | H < 15° 或 H ≥ 345° | ERR | 0–100%×B 呼吸 |
| 橙/黄 | 15° ≤ H < 75° | WAIT | 0–100%×B 呼吸 |
| 绿 | 75° ≤ H < 140° | NEW | 0–100%×B 呼吸 |
| 海绿 | 140° ≤ H < 175° | NEW | 100%×B 常亮，保留录音外观例外 |
| 青 | 175° ≤ H < 195° | OTHER | 0–100%×B 呼吸 |
| 蓝 | 195° ≤ H < 275° | RUN | 0–10%×B 呼吸 |
| 紫/粉 | 275° ≤ H < 345° | OTHER | 0–100%×B 呼吸 |

亮度 B 不参与色类判断，深浅色仍按相对色相分类；B=0 时灯可以黑但标签仍为 RUN 等。只有未分配或 off 显示 --；全黑基色仍可能配合彩虹/渐变发光，不能据此判定无任务。阈值是可解释的通用启发式，不是标准协议规定：宿主若用紫色表示运行，会显示 OTHER；红色品牌预览也会推断为 ERR，不能据此认定任务真出错。海绿常亮同样不能证明正在录音。要精确业务状态，需要宿主另发明确语义；现有报文不能保证这一点。

原始 c/b/e/s 与动画时钟保存在灯态中；`apply_light_adjustments()` 仅修改本次渲染的亮度/效果副本，随后按原始 c 渲染，不回写宿主参数。部分更新、换色/换效果时不会叠加前次降亮。按键本地白光属于另一种输入反馈，不是改写宿主 RGB。

## 第四排环境灯和本地反馈

以下优先级只在共享电源策略允许显示时生效。`0.4.6-qmk` 的 USB 挂起、Codex 全部灯态关灯及一小时空闲均会屏蔽所有 RGB/OLED，包括 ACT/切层按住白光；心跳只续时，不能推翻宿主关灯。息屏期间输入仍上报，一秒退出不变，原参数不清空。

`0.4.5-qmk` 增加灯槽 6–12 对应 ACT06–ACT12：收到扩展任务时，该键的任务灯态优先于下表的环境及按压反馈；e=off 释放后恢复原规则。已安装 Cindy 仍只下发六路，这不是十三路端到端完成。OLED/RGB 休眠、物理映射与其他未实现字段的必要性见 [兼容性评估](lighting-compatibility.md)。

| 场景 | 灯位 | 基色 | 亮度 | 样式 |
|---|---|---|---|---|
| 蓝色系跑马，常用于运行提示 | 第四排四灯 | 保留宿主蓝色 | `0–10% × B` | 四颗同步呼吸，跟随宿主速度 |
| 海绿色系跑马，常用于录音提示 | 第四排四灯 | 保留宿主海绿色 | `B` | 四颗常亮，不闪烁 |
| 白/灰系跑马，常用于语音处理 | 第四排四灯 | 保留宿主白/灰色调 | `0–100% × B` | 四颗同步呼吸，跟随宿主速度 |
| 白/灰系常亮，常用于待发送 | 第四排四灯 | 保留宿主白/灰色调 | `B` | 常亮 |
| GPT 发出的其他环境常亮提示 | 第四排四灯 | 保留 GPT 原色 | `B` | 常亮 |
| GPT 清除环境提示，且未按住 | 第四排四灯 | 无光 | 0 | 熄灭 |
| 普通 ACT 按住，无环境提示或不在环境灯区 | 被按住的 ACT | 白 `#FFFFFF` | 本地 100% | 按住亮，松开灭 |
| 普通 ACT 未按住且无环境提示 | ACT06–ACT12 | 无光 | 0 | 熄灭 |
| 切层键按住 | R4C1 | 白 `#FFFFFF` | 本地 100% | 按住亮，松开灭 |
| 空位 | R1C1、R1C4 | 无光 | 0 | 熄灭 |

第四排从左到右是切层键 / ACT10 / ACT11 / ACT12，对应 R4C1–R4C4、LED 12–15。这里映射整个 ambient 区域，所以 GPT 为运行任务发送蓝色跑马时，第四排会蓝色呼吸，并不只在录音时亮。固件跟随宿主的提示生命周期，不另加超时或自行判断语音状态。六个 AG 和第三排 ACT 不受环境灯覆盖。

灯光协议没有独立“正在录音”字段，当前以 ambient/underglow 的海绿色类 + snake 保留录音外观例外，输出常亮。它是色类规则，不是根据业务字段识别录音；不能保证任意自定义主题下都不误判。显式 off、零亮度与清除仍会熄灭；同色 AG 的 snake 转为呼吸，不套用环境常亮例外，显式 breath 不改成常亮。

环境呼吸使用与原生 breath 相同的明暗波形并保留原色；蓝色类 snake 的峰值为 10%×B，白/灰等其他色类为 B，海绿例外常亮。它是蓝色环境外观的降亮规则，不能在缺少显式状态的协议上保证“只在真正运行时”生效。显式 solid/breath/shallowBreath 不套用这些环境例外，白色环境也不套用 AG Idle 的 5%。默认速度 0.4 时约 1.37 秒一周期，速度 0 暂停当前相位。优先级、ACT 按压恢复和 1 秒退出不变。

## 环境呼吸与原始跑马

宿主发送的是 `snake`（数字 2），即亮段沿灯带依次移动的跑马/流光，不是整组同时亮灭，也不是整体明暗呼吸。OpenMicroKbd 参考实现采用亮头与渐暗拖尾，不能据此承诺与原厂逐帧相同。

```text
原始跑马示意：■□□□ → □■□□ → □□■□ → □□□■ → 循环
当前同步呼吸：全暗 → 四颗一起渐亮 → 设定峰值 → 一起渐暗 → 全暗 → 循环
```

示意只说明位置移动和同步明暗变化的差别，不代表原厂真实尾迹长度。运行蓝色提示的峰值为 `10% × B`，其他非录音 snake 的峰值为 B。历史上 `0.3.1-qmk` 将环境 snake 映射为 5 Hz 四灯快闪；用户随后明确改为呼吸，`0.3.2-qmk` 已更改。`0.4.4-qmk` 再按用户要求把 AG 的 snake 也改为原色 0–100%×B 呼吸，保留录音海绿环境常亮；没有恢复沿灯序移动的跑马。

## 七种协议灯效

| 编号 | 宿主效果 | KB16 输出 | 亮度和速度 |
|---|---|---|---|
| 0 | `off` | 熄灭 | 0 |
| 1 | `solid` | 原色常亮 | `100% × B`；AG Idle 常亮乘以 5% |
| 2 | `snake` | AG 原色呼吸；第四排环境同步呼吸；录音海绿环境常亮 | AG 为 `0–100% × B`；运行蓝色环境 `0–10% × B`，其他非录音环境 `0–100% × B`，均跟随宿主速度，0 暂停；录音持续 `B` |
| 3 | `rainbow` | 彩虹色循环 | `B`，保留宿主速度 |
| 4 | `breath` | 原色呼吸 | `0–100% × B`，保留宿主速度，不叠加 Idle 降亮 |
| 5 | `gradient` | 渐变 | `B`，保留宿主速度 |
| 6 | `shallowBreath` | 原色浅呼吸 | `50%–100% × B`，保留浅呼吸范围和宿主速度，不叠加 Idle 常亮降亮 |

彩虹和渐变自身会改变颜色，不再叠加自定义色表。数字 0–6 和对应字符串名均可解析，缺失参数保持旧值，未知效果编号保持已有灯效。

动画类型和速度时钟参考 OpenMicroKbd；普通呼吸和 AG snake 转呼吸为 0–100%，运行蓝色环境 snake 为 0–10%，不能声称与未公开的原厂曲线逐帧一致。宿主速度为 0 时动画停在当前相位；AG 不再有固定频率快闪例外。8 位 PWM 会带来取整，例如满全局亮度下 5% 白约为 RGB `(13,13,13)`，运行蓝色呼吸峰值约为 RGB `(5,8,25)`；这些比例是固件输出，不代表精确的实测光通量。
