# FAQ

## Mapper 是什么？

Mapper 是上游的 Windows x64 键位/灯光配置器，不在本仓库。本仓库只负责生成固件；改键用 VIA（PoC）或外部上游 Mapper。

## 为什么刷完 VIA 不能用？

Codex 固件关闭了 VIA，USB 身份也变成 `303A:8360`。本仓库的 PoC 目标是把 VIA 加回来，只让 VIA 改层 1-3；层 0 保持 Codex 原生。

## 6 个任务灯能显示“当前任务”吗？

现在 host 会把“当前选中/需要关注”的任务发成呼吸效果；其他五个是常亮状态色。要更明显（当前白色呼吸、其他变暗）需要改 `codex_micro_protocol.c` 重新编译；外部 Mapper 也不改这个逻辑。

## 摇杆只能上下左右吗？

在 Codex 里是。官方硬件是模拟摇杆，但 Codex 只取四个方向；斜推归到最近主方向，没有 8 方向/力度/连续滚动。KB16 只有四个数字方向键。

## 左下角那个是什么？

官方 Codex Micro 左下角是触摸传感器，用来切层；最多 6 层，旁边 3 个 LED 显示当前层。KB16 没有这个传感器。

## OLED 能显示自定义图案吗？

能，但要改固件重编译。当前是 128×32 单色、512 字节一帧；可以替换 4 个 24×24 层图标，或写全屏 512 字节数组/动画。不能运行时上传图片，不支持彩色/GIF。

## 能无线吗？

KB16-01 是有线版；Codex 固件只支持有线。无线 KB16B-02（`FEED:6060`）不在支持范围。

## 刷坏了怎么办？

进入 Bootloader（按住左上角键插 USB），刷回官方 Rev2 VIA 3.0 固件。如果 VIA 读不到键位，整片擦除或恢复默认后再写。

## Mac 上怎么改键？

本仓库不含 Mapper。可以用本仓库的 VIA PoC（macOS 浏览器打开 VIA 网页），或使用外部上游 Mapper（Windows x64）。ChatGPT 的 Codex 原生设置（AG/摇杆/旋钮/麦克风）在 macOS 上可以直接用。

## 官方 Codex Micro 和 KB16 怎么选？

要官方成品、无线、触摸、模拟摇杆 → Codex Micro。要更多键/旋钮、OLED、自定义图案，并能接受有线和逆向协议 → KB16 + Codex 固件。

## 任务灯不亮/颜色不对？

先确认 ChatGPT 已连接、设备被识别为 Codex Micro、当前在 Codex 层。任务灯由 host 的 `v.oai.thstatus` 驱动；如果 host 没发状态，灯会保持熄灭或默认色。
