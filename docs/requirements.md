# DOIO KB16 Codex Micro 固件需求文档

> 当前定稿 `0.4.8-qmk`：四层（L0–L2 普通 VIA，L3 固定 Codex），上电 10 秒 VIA 窗口、Codex 左下角长按 1 秒回 L0；含留边 Logo/任务页及 VIA 实时输出。构建及离线验证通过，本版未刷入。
> 硬件：DOIO KB16-01 Rev2，APM32F103CBT6，128 KB Flash / 20 KB RAM。
> 仓库只负责生成固件：QMK + VIA，不包含 Mapper；Git 不提交预编译产物，固件通过 GitHub Release 分发。

## 1. 项目目标与边界

- KB16 的 16 键、3 旋钮及 128×32 单色 OLED 提供 Codex Micro 兼容的原生控制，同时保留普通键盘改键。
- 使用 `firmware/keymaps/codex_micro_via_v1/` 和相应 QMK core patch；Rust/embassy、旧上游 keymap 仅作历史参考。
- 不需要额外常驻 host 程序；不做 Input 改键、`fs.*`、Mapper/Channel 3、AppSense/六层、触摸、无线或连续模拟摇杆。
- 不在同一层混排 Codex 原生键与普通 VIA 键；不提供运行时图片上传、彩色 OLED 或 GIF。
- 额度/任务标题同步需要额外程序，不纳入当前实现；旧可选方案仅作参考。

## 2. 四层与编辑语义

| 固件层 / VIA 页 | VIA 编辑保存 | 运行时 |
|---|---|---|
| L0 / 第一页 | 支持 | 执行普通动态键位/编码器 |
| L1 / 第二页 | 支持 | 执行普通动态键位/编码器 |
| L2 / 第三页 | 支持 | 执行普通动态键位/编码器 |
| L3 / 第四页 | 支持读写和保存 | 忽略本页改键，执行固件静态 Codex 表 |

- 只定义四层，不偏移，`DYNAMIC_KEYMAP_LAYER_COUNT=4`、`POC_CODEX_LAYER=3`，不存在可进入的 L4。
- 用户确认第四页仅为 Codex 入口，不是第四个普通键盘层；按键和旋钮的编辑值可读回，但不能改变实际 Codex 位置映射。
- 在普通层用 VIA 设置 `TO(3)` 等目标 L3 的层动作；建议直接切层 `TO(3)`，Codex 固定非透明键位会遮盖低层。
- 新初始化时旋钮 B 的 L0/L1/L2 按压依次进入 L1/L2/L3；已自定义的切层动作由用户控制。
- L3 左下角短按无动作，长按 1 秒退出到 L0；普通层不强占这个物理按键。
- OLED、灯光和协议层状态要使用实际激活层和默认层，避免 `DF(3)` 后显示/灯效错误；长按退出也要能离开默认 L3。

## 3. 10 秒 VIA 窗口与 USB 身份

```text
上电
 ├─ 10 秒内收到有效 VIA 命令 → 锁定 VIA 身份直到断电
 └─ 无 VIA 命令 → 自动复位成 Codex 身份，默认 L3
       ├─ L0–L2 → 普通键盘 HID，读取保存的 VIA 改键
       └─ L3 → Codex 专用 HID，静态 AG/ACT/ENC/JOY
```

| | VIA 身份 | Codex 身份 |
|---|---|---|
| VID:PID | `D010:1601` | `303A:8360` |
| Raw HID | `FF60:0061`，32 字节，无 ID | `FF00:0001`，Report ID 6，64 字节 |
| 协议 | VIA 四页读写 | Codex Channel 2 JSON-RPC |

- 有效 VIA 命令包含协议版本查询；错误长度、未知 ID、越界层等不得锁定。
- VIA 连接后不自动切回 Codex，写入完成后断电重插才重新给窗口。
- 切层不改变 USB 身份；VIA 锁定时即便进入 L3，也不能向 Codex 发送可用专用事件。必须断电、不连 VIA，等窗口超时。
- 模式标志使用备份寄存器 `BKP->DR9`，保留 bootloader 的 `DR10`。
- USB 重枚举使用安全软复位；Codex 报告与 VIA 报告不混用。
- Raw HID 中断接收按报告边界分派；控制 SET_REPORT 入队，由主循环处理，不在中断内写 EEPROM 或解析 JSON。

## 4. Codex 固定键位与任务灯

L3 按 [键位对应](keymap.md) 实现：

- R1C2/R1C3/R2C1–R2C4 = AG00–AG05；R3C1–R3C4 = ACT06–ACT09。
- 第四行右移：R4C1 = 长按切层，R4C2/R4C3/R4C4 = ACT10/ACT11/ACT12。
- R1C1/R1C4 空置；顶部旋钮 A/B = 摇杆 X/Y，下方旋钮 C = Codex 编码器 CC/CW/Press，A/B 按下无动作。
- ACT10+ACT11 可由宿主合并为 MIC 或拆成两个动作；固件不改变宿主侧功能绑定。
- AG 事件不依赖是否收到任务灯分配；按下/松开配对。旋转每格只发送一次，按压保留按下/松开。
- `v.oai.thstatus` 驱动六个 AG，`v.oai.rgbcfg`/环境预览映射第四排全部四灯（切层键、ACT10/ACT11/ACT12，LED 12–15），不只限 MIC 或录音。
- 原始 RGB 不改色；Idle 白色常亮为宿主亮度的 5%，普通常亮 100%，呼吸 0–100%，尊重全局亮度。
- AG 任意颜色 snake 转为原色 0–100%×宿主亮度呼吸，跟随宿主速度，0 暂停当前相位；白灰呼吸不叠加 Idle 常亮的 5%，不再固定 5 Hz。环境 snake 仍映射第四排四灯：蓝色类为 0–10%×宿主亮度同步呼吸，海绿色类例外常亮，其他颜色为 0–100% 呼吸；呼吸跟随宿主速度且 0 暂停，不用精确 RGB 白名单判断业务状态。
- ACT 无环境提示时默认灭、按住白光；第四排 ACT 的环境提示优先，切层键按住白光优先于环境提示；空位常灭，环境提示不得覆盖六个 AG。
- 进入 L3 临时启用 Codex 灯光，离开恢复普通 RGB 开关/效果，不额外写 EEPROM。
- 固件灯槽支持 0–12，扩展 6–12 对应 ACT06–ACT12 物理灯，输入仍上报 ACT；任务灯态（含 B=0）优先于环境/按压，off 释放。现有 Cindy 只下发六路，十三路需宿主配套，不声称端到端已完成；OLED 原六格不变，映射及边界见 `lighting-compatibility.md`。
- 休眠以当前层为准：VIA L0–L2 空闲一小时同时关闭 OLED/RGB；Codex L3 跟随任务/环境聚合灯态全部 off/零亮度关闭，任一组恢复则点亮，另有一小时无活动兜底。输入、有效心跳和重复报文均续时，不能仅在状态变化时续时；心跳不能推翻宿主明确关灯，呼吸低点不代表关灯。USB 挂起二者同灭，允许恢复时即使 OLED 帧不变也点亮；不清空灯态或改 EEPROM。完整优先级见 `lighting-compatibility.md`。
- 完整颜色、亮度和样式见 [灯光](lighting.md)。

## 5. OLED

- 冷启动十秒 VIA 等待期居中显示 `VIA WAITTING`，不显示 DOIO 启动页；收到 VIA 命令锁定后恢复普通页，无命令超时后进入 Codex 的 Logo+CODEX/任务页。使用实际模式窗口状态，不改变 USB/层或既有休眠策略。

- 128×32 单色，512 字节/帧；左右至少 6 px、上下至少 4 px 留黑，不贴屏幕边沿。
- 切到 L3 先显示旧终端图标+CODEX 约 1 秒，随后显示六个已有 AG 任务状态；不新增宿主程序，不显示任务标题/额度或旧通用弹窗。
- VIA L0–L2 显示居中 1/2/3，包含默认层；成功入队的 USB 输出临时替换数字为实际键名/组合/媒体/鼠标，按住保留、松开约 900 ms 恢复层号。
- 显示最终 6KRO/NKRO 等报告，而非旧默认键位；宏只显示最近输出，不获取输入法/应用最终文字，不保存输入历史。详见 `oled.md`。

## 6. 保存、迁移与安全

- VIA 四页键位/编码器及宏保存到 EEPROM；重启后 L0–L2 直接使用配置，L3 页面内容保留但不执行。
- Codex 物理映射固定，不存在 Input/Mapper 两套物理改键数据。
- 五层缩四层保持旧键位、编码器、宏起址和宏容量，以未使用空间兼容地址，不产生第五个运行层。
- 一次迁移 L0–L2 按键及编码器中指向旧 L4 的 TO/MO/DF/PDF/TG/OSL/TT/LT/LM 到 L3；保留其他键、第四页及宏，后续 VIA 编辑不反复覆盖。
- 刷前导出 VIA 配置；地址兼容不代表任意构建/导入都不会触发 QMK/VIA 配置重置。
- 不自动刷写；核对版本、镜像 SHA-256、DFU 身份和板型后，在用户要求下刷写。
- 只支持 Rev2，不在 Rev1/无线版刷入；不改 bootloader/读保护。保留官方回退镜像，见 [使用](usage.md)。
- 不提交 `.bin/.hex/.uf2/.elf/.map`，构建产物留在仓库外。

- 固定 QMK commit `f5db962110615fd263c3ebf9f0402e7c2b08fbe4`，安装脚本拒绝其他基线。

- 上一版 `0.2.0-qmk` RPC 和八组灯光实机通过是历史结果，不代表当前四层、OLED 或录音常亮已验收。
- 固件协议来自兼容性实现，不是稳定官方承诺；宿主升级后应重测。

## 8. 新版实机验收

1. VIA 窗口内连接后锁定身份，超过 10 秒仍不切换；断电后重新计时。
2. VIA 显示四页，L0–L2 改键和三个旋钮保存并执行；第四页改值可读回但不执行。
3. 不连接 VIA，10 秒后重新枚举为 Codex，默认 L3；AG/ACT/ENC/JOY 正常。
4. L3 长按左下角 1 秒进入 L0，普通层通过 `TO(3)` 返回，无 L4。
5. 旧目标 L4 迁移为 L3，不重置其他配置；刷前备份与恢复可用。
6. OLED 留边；Codex Logo→任务页、VIA 层号→按键→空闲恢复均正确，默认层与 VIA 改键后的输出一致。
7. 按 [灯光](lighting.md) 逐项核对原色、Idle 5%、普通常亮、呼吸范围及海绿录音常亮，确认 AG 不被 MIC 覆盖。
8. 验证能通过 RET 进入 `1EAF:0003` 并回退；区分下载完成、重新枚举、RPC 和光学测量，不将未验证项目标成通过。
