# Codex L0：五处 VIA 自定义

## 版本与层序

当前版本 `0.6.0-qmk`：**第一页 L0 为 Codex，L1–L3 为普通 VIA 层**，总共四层。取消固定长按退出、短按松开重放和退出白光。本版已使用对应提交的 main 流水线 Artifact 刷入，版本/状态应答确认 0.6.0-qmk、当前 Codex L0；没有使用本机镜像。用户随后整体反馈“正常的”，不等于逐项精测或一小时休眠验收。

原生六个 AG、七个 ACT、三个旋钮的旋转和 C 按下固定。仅以下五处读取 **VIA 第一页 / L0**；其余第一页编辑值可存储但不替代原生控制。

| 图中标记 | 物理位置 | VIA 矩阵坐标 | 行为 |
|---|---|---|---|
| VIA1 | 左上方键 R1C1 | `0,0` | 直接执行，支持按住，无固定长按 |
| VIA2 | 右上方键 R1C4 | `0,3` | 直接执行，支持按住 |
| VIA3 | 顶部旋钮 A 按下 | `0,4` | 直接执行；旋转仍是摇杆 X |
| VIA4 | 顶部旋钮 B 按下 | `1,4` | 直接执行；旋转仍是摇杆 Y |
| VIA5 | 左下方键 R4C1 | `3,0` | 直接执行，支持按住 |

VIA1–5 是位置编号，不是层号或新 keycode。三组旋转不读取 L0 动态 encoder map，C 按下仍为 `ENC_SW`。普通 L1–L3 的按键、按压和旋转均由 VIA 配置。

## 推荐切层配置

1. 真正断电重插，在十秒 `VIA WAITTING` 内让 VIA 成功读取键位；之后锁定 VIA 身份直到断电，不必十秒内改完。等待/锁定身份默认普通 L1。
2. 第一页左下角设置 **`MO(1)`**，Any 可填 `0x5221`。Codex L0 下按住后激活普通 L1，可同时按该层其他键；松开恢复 Codex。
3. 需要常驻普通层时用 `TO(1)`、`TO(2)` 或 `TO(3)`；给普通层留 **`TO(0)`** 返回 Codex，Any 为 `0x5200`。
4. 五处均可使用 QMK 正常按键流程，支持普通键、修饰组合、媒体、VIA 宏及层动作；左上角也立即响应，不等松开。没有保底长按逃生键，请自行配置入口；误配可在下一次开机 VIA 窗口修复。
5. 配完断电重插，关闭 VIA，让窗口超时进入 Codex USB 身份，默认 L0。切层不改变 USB 身份；锁定 VIA 时即使在 L0，Codex 接口也不可用。

`MO` 保留标准 QMK 的最高有效层优先规则。Codex 位于最低 L0，`MO(1/2/3)` 可以自然临时覆盖。普通高层向低层的 MO 并不是强制切层，不承诺遮盖更高层；要完全换层使用 `TO`。普通层透明键在普通基底 L1 查找，不能漏出 Codex 原生控制。源层缓存保持按下和跨层松开的配对。

五处的 `KC_TRNS` 按无动作处理；AG/ACT/JOY/ENC 和历史退出内部码不允许从五处注入。层索引限定 0–3；无第五层。

## 旧配置迁移

| 旧 0.5.0 页 | 新 0.6.0 页 |
|---|---|
| L3 Codex | L0 Codex |
| L0 普通 | L1 普通 |
| L1 普通 | L2 普通 |
| L2 普通 | L3 普通 |

- 一次性旋转全部四页键位及 encoder map，`TO/MO/DF/PDF/TG/OSL/TT/LT/LM` 的有效目标也按同样顺序转换；LT 的轻触键及 LM 修饰位不变。原 Codex 左下 `MO(0)` 因而成为新 L0 的 `MO(1)`。
- 从 0.5.0 升级保留现有五处编辑，不再清空；更早占位页升级先沿用旧安全迁移，再调整层序。旧五层指向 L4 的动作先迁移至旧 L3，再变为新 L0。
- 标记仍在原 8 字节用户 EEPROM 内，键位、旋钮、宏起址及宏容量不变；宏数据不重写。新初始化的默认布局直接带新标记，不重复旋转。
- **刷前导出备份**。迁移不是断电事务，期间保持供电；不保证任意旧固件/反复降级升级兼容。导入旧顺序 JSON 不会自动再次迁移，需先转换页序与层动作目标。
- 五处全新默认 `KC_NO`；请主动设置切层键。普通新默认的 B 按压为 L1→L2→L3→L0，不把它写死在 Codex 的 B 按下上。

## 屏幕与灯光

- 普通 L1/L2/L3 空闲居中显示 **1/2/3**（VIA 第 2/3/4 页）。Codex L0 入层 Logo+CODEX，随后六格任务页，无任务保留 Logo。
- 任一普通 HID 输出成功入队后显示真实键名/组合/媒体/鼠标；按住保留，松开约 900 ms 恢复页面。宏显示最近输出；原生 Codex Raw HID 不伪造普通键名。层动作只反映层页面，不虚构按键输出。
- 移除专用退出白光：R1C1/LED0、R1C4/LED3 无本地反馈；R4C1/LED12 仍跟随第四排环境。其他 AG/ACT 色彩、亮度、效果、扩展灯槽、OLED 留边/一小时息屏/心跳续时不改。
- 任务灯全灭不关闭 OLED；USB 挂起与一小时无输入且无有效通信才息屏。原生 RGB/OLED 超时策略不另改。
