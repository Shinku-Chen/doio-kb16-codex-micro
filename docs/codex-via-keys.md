# Codex 层的五处 VIA 自定义键

## 版本与范围

开发源码 `0.5.0-qmk` 支持本页功能。设备目前仍运行已发布并刷入的 `0.4.9-qmk`；新版尚未发布或刷入，不能把离线检查当作实机验收。

仍是四层：L0–L2 为普通 VIA 层；L3 保留 13 个 AG/ACT 原生键、两个摇杆旋转轴和 C 编码器，同时开放以下五处。VIA 显示四页，在第四页（索引 3）修改；其余第四页内容可保存，但不改变原生 Codex 控制。

| 图中标记 | 物理位置 | VIA 矩阵坐标（从 0 开始） | 行为 |
|---|---|---|---|
| VIA1 | 左上方键 R1C1 | `0,0` | 短按松开执行所配动作；长按满 1 秒固定回 L0 |
| VIA2 | 右上方键 R1C4 | `0,3` | 普通 VIA 按键，可按住 |
| VIA3 | 顶部旋钮 A 按下 | `0,4` | 普通 VIA 按键，可按住；旋转仍是摇杆 X |
| VIA4 | 顶部旋钮 B 按下 | `1,4` | 普通 VIA 按键，可按住；旋转仍是摇杆 Y |
| VIA5 | 左下方键 R4C1 | `3,0` | 普通 VIA 按键，可按住；不再强制长按切层 |

VIA1–5 只是图中位置编号，不是层号或新 keycode。C 按下仍是 `ENC_SW`，三旋钮的旋转不执行第四页 encoder map 的修改。

## 修改和保存

1. 使用本仓库 VIA 定义，真正断电后重新插入，在十秒 `VIA WAITTING` 窗口内让 VIA 成功读取键位；随后可一直编辑到断电，不必十秒内完成全部设置。
2. 在第四页给上述五个位置设置普通键、修饰组合、媒体键、宏或层动作。四个直接位置使用 QMK 正常按键流程，可用作持续按住的修饰键或双功能键。
3. 左上角按下时不先发键，短按松开后重放一次配对的 QMK 按下/松开，可触发 VIA 宏；达到一秒只切 L0，不执行短按。它不能同时作为持续按住的 Ctrl/MO 等键；MT/LT 只能执行其轻触一侧，持续层动作不适合配置在这里。左下角属于前述四个直接位置，长按也只执行 VIA 定义，不再强制退出。
4. 改完断电，关闭 VIA 并让十秒窗口超时，以 Codex USB 身份启动。五处配置保存在 EEPROM，L3 立即使用；USB 身份仍不随切层改变，Codex 身份下不能在线连接 VIA 改键。

五处的 `KC_TRNS` 按无动作处理，不穿透到 L0。原生 AG/ACT/JOY/ENC 和退出内部 keycode 不允许从这五处注入，避免增加伪原生键或递归。普通 QMK 层动作仍遵守四层边界。

## 升级与默认值

旧版本的第四页全部不执行，里面可能保留未知键值。首次升级时**仅将这五处清为 `KC_NO`**，避免刚升级就误触；L0–L2、其他第四页存储、旋钮映射和宏不重置。之后改键不再重复清空。

迁移标记复用原来 8 字节用户区内的第二个 32 位字；四层迁移识别新标记，不反复迁移。动态键位、encoder map、宏的 EEPROM 地址和容量不变，未增加用户区或第五层。刷前仍需导出 VIA 配置，回退旧版本再升级不保证保留这五处设置。

## OLED 提示

- 五处发出普通 HID 输出时，临时覆盖 Codex Logo/任务页，显示实际键名或组合，如 `ESC`、`GUI+C`、`VOL UP`、鼠标输出；宏显示最近的实际输出，不显示虚构的宏动作名称。
- 按住期间保留提示，松开后约 900 ms 回到六格任务状态；无任务灯分配时回 Logo+CODEX。切层清除旧提示，正常入层仍显示 Logo；实际自定义输入的提示优先于入层 Logo，启动 `VIA WAITTING` 优先级不变。
- 与普通 VIA 层一样，只观察成功入队的 6KRO/NKRO、消费/系统和鼠标报告。层切换、RGB 等没有普通 HID 输出的操作不伪造键名，直接反映实际层页面/灯态；不读取输入法文字、不保存输入日志、不加 host daemon。
- 原生 AG/ACT/JOY/ENC 走 Codex Raw HID，不会被这项功能转换为普通键或覆盖任务页。长按切层的白光反馈随按钮移到左上角 LED 0；第四排环境灯仍是 LED 12–15，左下角不再叠加切层白光。其余自定义位置不新增本地白光，任务灯的颜色、亮度、效果和优先级不变。
- OLED 独立一小时息屏、有效心跳/重复报文续时和 USB 挂起优先级沿用 0.4.9。

离线覆盖五处动态路由、原生键/旋转固定、透明与原生内部码过滤、五处一次迁移、EEPROM 起址、左上角 999/1000 ms、漏过 scan 后的长按松开、短按映射快照、跨层成对松开、实际 QMK VIA 宏分发、左下角长按不退出、OLED 组合/宏/媒体提示和 900 ms 恢复；两份 SVG 还与实际 keymap/旋钮/VIA 坐标自动核对。69 组固件检查、13 项打包测试及本地 QMK 编译通过，实机改键、短按/长按、OLED 及一小时息屏仍须另外验收；正式固件必须由 GitHub Actions 构建，不把本地镜像冒充 Release。
