# Codex L0：VIA 优先，空键回退

## 版本与层序

当前版本 `0.7.2-qmk`：**第一页 L0 为 Codex，L1–L3 为普通 VIA 层**，总共四层。L0 的全部 16 个方键、三个旋钮按下和六个旋转方向均支持 VIA 覆盖；空键回退到该位置原生 Codex 功能。没有固定长按退出、延迟重放或退出白光。Codex L0 的全部 16 个方键逐键按住白光，RGB/OLED 取消一小时空闲关闭；普通 VIA L1–L3 保留一小时计时。0.7.2 加入 EEPROM 兼容修复：固定 `KB` + schema 1 marker，只校验格式标记而非 payload CRC；0.7.1/更旧首次升级恢复一次 VIA 默认并写 marker，之后同 schema 跨日期/版本保留，不迁移旧页序/自定义位置。2026-11-04 用户确认“按下白光”通过（`db2cdf1` 同逻辑开发镜像）；正式 0.7.2 未刷入，普通层灯光、真实长时间无空闲关闭及 Flash 读回未验收。

## 第一页如何执行

| VIA 第一页 / L0 的内容 | 实际执行 |
|---|---|
| 普通键、修饰键、组合键、媒体、鼠标、宏、`MO/TO/LT` 等 | 按 VIA 配置交给 QMK，不再同时发送原生 Codex 事件 |
| `KC_NO`（空键）或 `KC_TRNS`（透明键） | 回退到该物理位置的 AG/ACT/JOY/ENC 默认功能 |
| 空键，且该位置原本没有 Codex 功能 | 无动作 |
| 原有 AG/ACT/JOY/ENC/旧切层内部码 | 视为原生占位，回退该位置默认功能，不用于搬移或注入内部事件 |

例如把 AG00 所在 R1C2 配为 `MO(1)`，按住进入普通 L1，松开回 L0；清空为 `KC_NO` 或 `KC_TRNS` 后恢复 AG00。A/B/C 的顺、逆时针独立读取 VIA 编码器配置；清空某个方向只恢复该方向的原生功能。C 按下也可覆盖，清空恢复 `ENC_SW`。

**仅 L0 使用空键回退规则。** 普通 L1–L3 的 `KC_NO` 仍是禁用、`KC_TRNS` 仍是普通层透明继承；L0 的空键不能用于禁用有原生功能的位置。当前 schema 内原生默认内部码仍存储在原地址，不需要清空 EEPROM、增加迁移标记或改变 VIA 层数。

下面五处原本没有原生功能，标记 VIA1–5 沿用旧图；现在不代表仅五处可以改：

| 图中标记 | 物理位置 | VIA 矩阵坐标 | 行为 |
|---|---|---|---|
| VIA1 | 左上方键 R1C1 | `0,0` | 直接执行，支持按住，无固定长按 |
| VIA2 | 右上方键 R1C4 | `0,3` | 直接执行，支持按住 |
| VIA3 | 顶部旋钮 A 按下 | `0,4` | 直接执行；旋转仍是摇杆 X |
| VIA4 | 顶部旋钮 B 按下 | `1,4` | 直接执行；旋转仍是摇杆 Y |
| VIA5 | 左下方键 R4C1 | `3,0` | 直接执行，支持按住 |

VIA1–5 是位置编号，不是层号或新 keycode。全部原生位置同样可覆盖；未覆盖时仍沿用 [默认键位图](keymap.md)。

## 推荐切层配置

1. 真正断电重插，在十秒 `VIA WAITTING` 内让 VIA 成功读取键位；之后锁定 VIA 身份直到断电，不必十秒内改完。等待/锁定身份默认普通 L1。
2. 第一页左下角设置 **`MO(1)`**，Any 可填 `0x5221`。Codex L0 下按住后激活普通 L1，可同时按该层其他键；松开恢复 Codex。
3. 需要常驻普通层时用 `TO(1)`、`TO(2)` 或 `TO(3)`；给普通层留 **`TO(0)`** 返回 Codex，Any 为 `0x5200`。
4. 全部位置均可使用 QMK 正常按键流程，支持普通键、修饰组合、媒体、VIA 宏及层动作；立即响应，不等松开。没有保底长按逃生键，请自行配置入口；误配可在下一次开机 VIA 窗口修复。
5. 配完断电重插，关闭 VIA，让窗口超时进入 Codex USB 身份，默认 L0。切层不改变 USB 身份；锁定 VIA 时即使在 L0，Codex 接口也不可用。

`MO` 保留标准 QMK 的最高有效层优先规则。Codex 位于最低 L0，`MO(1/2/3)` 可以自然临时覆盖。普通高层向低层的 MO 并不是强制切层，不承诺遮盖更高层；要完全换层使用 `TO`。普通层透明键在普通基底 L1 查找，不能漏出 Codex 原生控制。源层缓存保持按下和跨层松开的配对。

层索引限定 0–3；无第五层。两种 USB 身份共用保存的键位；Codex 原生事件仍需要 Codex USB 身份，普通 VIA 覆盖输出不需要宿主应用。

## EEPROM 兼容与升级

0.7.2 只接受固定 `KB` + schema 1 的 VIA 三字节 marker，不再用编译日期或固件版本判断配置是否有效；三字节只校验格式标记，不是 payload CRC。

- 当前 schema 在 VIA 配置初始化路径原样保留四页键位、三个 encoder、宏和布局选项；只读不写，不宣称整个固件运行永不写 EEPROM。跨编译日期或固件版本仍保留。
- 0.7.1/更旧的日期 marker、旧 schema、未知值、全 FF、全 00 首次启动恢复一次默认，并写入当前 marker；第二次启动不再重置。
- **不自动迁移旧页序、自定义位置或旧层动作。** 首次升级前必须导出 VIA 配置；旧顺序备份不能直接作为当前布局导入，需要自行转换或重新配置。
- 保留原 8 字节用户 EEPROM 区、`POC_EEPROM_RESERVED_LAYER_SLOTS=5` 以及键位/encoder/宏起址与容量。只有存储布局或编码不兼容改变时才手动升 schema。
- 非当前 marker 由默认初始化 helper 恢复 VIA 默认并写入当前 marker，不做迁移；不新增远程清空权限。五处空余位置全新默认 `KC_NO`，请主动设置切层键；普通新默认的 B 按压仍为 L1→L2→L3→L0。

## 屏幕与灯光

- 普通 L1/L2/L3 空闲居中显示 **1/2/3**（VIA 第 2/3/4 页）。Codex L0 入层 Logo+CODEX，随后六格任务页，无任务保留 Logo。
- 任一位置的 VIA 覆盖产生普通 HID 输出成功入队后，显示真实键名/组合/媒体/鼠标；按住保留，松开约 900 ms 恢复页面。宏显示最近输出；原生 Codex Raw HID 不伪造普通键名。层动作只反映层页面，不虚构按键输出。
- **灯光不随按键覆盖改成另一套规则。** AG 原物理位置仍接收对应宿主任务灯；ACT 本地白光由实际原生 ACT 事件驱动，覆盖为普通 VIA 键后不额外添加白光。第四排环境灯、扩展灯优先级、宿主原色/亮度/效果及一小时休眠均保持不变。
- 移除专用退出白光：R1C1/LED0、R1C4/LED3 无本地反馈；R4C1/LED12 仍跟随第四排环境。其他 AG/ACT 色彩、亮度、效果、扩展灯槽、OLED 留边/一小时息屏/心跳续时不改。
- 任务灯全灭不关闭 OLED；USB 挂起与一小时无输入且无有效通信才息屏。原生 RGB/OLED 超时策略不另改。

## 验证边界

离线测试覆盖全部按键/按压/旋转的 VIA 覆盖与空键回退、实际静态默认键位、跨层松开配对、无重复 Codex 事件、普通透明继承、EEPROM marker/存储、RGB/OLED，以及两份 SVG 对应实际 keymap/VIA 坐标。测试不等于实体端到端验收；正式刷写只使用 GitHub Actions 产物，本版未刷入。历史 `v0.6.0-qmk` 的整体使用确认不能当作新功能验收。
